## Всем привет! 👋
Я — HTML5 Game Developer с интересом к интерактивным веб-технологиям. Помимо классических интерфейсов, я создаю браузерные игры, которые быстро загружаются, удерживают игроков и масштабируются для мультиплеера.
Оптимизирую бандлы, строю real-time механики и разрабатываю переиспользуемые архитектуры.
